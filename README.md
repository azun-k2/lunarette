# Lunarette

Support pages and privacy policy for **Lunarette** (on the App Store as *Lunarette: Lunar Calendar*), a macOS menu bar
lunar calendar. Served by GitHub Pages at <https://azun-k2.github.io/lunarette/>.

Icons are regenerated from the app with `../_tools/make-site-icons.py` run in `../Lunarette`.
